# Friends

The 0.8.0 pilot includes a collapsible friends panel and case-preserving player
names. A user can opt into discovery using a friend code. Names and email
addresses are not invitation identifiers in this version.

The recipient must confirm a request before the two users become friends.
Confirmed friends can see each other's presence and level. Requests can be
declined; friendships can be removed and users blocked. Chat is optional and
available only within an eligible confirmed friendship.

See [release notes](RELEASE-0.8.0.md) for acceptance boundaries. Real two-user
acceptance remains open; this document is not a deployment record.
