# Asterion sculpt-v006 — facial refinement

Editable authority: `asterion-sculpt-v006.blend`. Browser delivery:
`public/assets/3d/asterion/asterion-sculpt-v006.glb` from the repository root.
The [manifest](manifest.json) binds the unchanged approved four-view reference,
previous v005 master/GLB, authoring modules, saved source and fresh-import views.

This is a face-only revision: larger deep-blue eyes, physical orbital-to-skin
transitions, lighter brows, softer cheeks/chin, a rounded triangular nasal
volume with seated nares, and narrow curved lip arcs. Lower lid sweep ends are
closed. Facial pigment uses dedicated materials so nonfacial shaders remain
unchanged. The head mane remains intentionally omitted; native tail hair is
retained without physics. Crown, ears, body and detachable armor are unchanged.

The original 22-bone rig, all nine actions, drivers, constraints, frame rate and
lid pivots are preserved. The inherited center-expanding eye-cover animation
is not reauthored; this does not claim anatomical or collision-free blinking.
The sculpture is closer in selected facial features, not an exact reproduction
of painterly lighting, hidden views or the original mane silhouette.
