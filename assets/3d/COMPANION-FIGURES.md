# Companion figures

Distributed files are metadata-clean publication copies. See the
[publication amendment](publication/2026-09-07/README.md) for the distinction
between current file hashes, preserved asset content and historical authoring
receipts. Original pre-publication bytes remain privately retained.

The current face-only round uses Asterion `sculpt-v006` and `sculpt-v005` for the
other seven figures. Only eyes, facial skin, cheeks/muzzle, nose, mouth, lids,
lashes and facial markings change. All nonfacial geometry/materials and original
animation data remain unchanged. The outer outfit remains independently removable.

The historical [v002 collection review](reference/companions/sculpt-v002/REVIEW.md)
links each figure's measured evidence and remaining likeness differences.
The gallery renders the five actual delivered GLBs together in Blender, with
display heights normalized for comparison. It is not a body-scale chart.

The opt-in `/3d-preview` route supports all eight pets, free rotation, four fixed
views, nine clip controls and a per-pet outfit toggle. `NEXT_PUBLIC_ASTERION_3D_ENABLED=true` enables the
local preview; the repository default remains off.

The clips are simple presentation gestures, not biomechanical motion. Missing
reference views are inferred. Final likeness approval and representative mobile
performance are not claimed. The models are fully volumetric, without image
projection or flattened reference planes.

See the [v002 reproduction guide](source/companions/sculpt-v002/README.md)
and [historical v002 collection manifest](reference/companions/sculpt-v002/collection-manifest.json)
for counts, hashes, provenance and validation boundaries. The historical
[v001 gallery](reference/companions/sculpt-v001/companions-gallery.png) and
[v001 manifest](reference/companions/sculpt-v001/collection-manifest.json)
remain available for comparison.
